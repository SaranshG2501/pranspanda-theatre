# 📌 About The Project

**Pranspanda Theatre** is a web-based seat booking and event management platform created for college club activities and theatre events.

The platform was developed to simplify seat reservation for:
- 🎬 Movie screenings
- 🎤 Seminars
- 🎭 Theatre performances
- 🏫 Club events

Participants can view available seats and reserve them interactively, while administrators have the ability to dynamically update seating layouts and manage bookings efficiently.

The project focuses on creating a clean, responsive, and user-friendly booking experience using lightweight web technologies. This project can be even live access at praanspandatheatre.netlify.app

# 🧬 System Workflow

## 1️⃣ Admin Creates Event Layout
Administrators configure or update the seating arrangement based on the event type.

## 2️⃣ Participants Access Booking Interface
Users can view the available seating layout in real time.

## 3️⃣ Seat Selection & Reservation
Participants select preferred seats and confirm booking.

## 4️⃣ Booking Status Update
Reserved seats are updated dynamically to avoid conflicts and duplicate reservations.

# 🚀 Installation & Setup

## Clone the Repository

```bash
git clone https://github.com/SaranshG2501/pranspanda-theatre.git

cd pranspanda-theatre
```

---

## Create Virtual Environment

### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

### macOS/Linux
```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python app.py
```

---

## Open in Browser

```bash
http://127.0.0.1:5000/
```
